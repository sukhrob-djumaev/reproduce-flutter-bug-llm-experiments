# Three-dot menu button in the last column does not open its menu

The app shows a table of rows. The rightmost column stays fixed on screen and each of its cells has a three-dot (more) button which should open a menu with an "Action N" entry for that row.

Steps:
1. Launch the app and leave the table at its initial horizontal scroll position.
2. Tap the three-dot button of any visible row in the fixed rightmost column.

Expected: A menu with an "Action N" entry opens for that row.

Actual: The menu does not open.  When the table is scrolled fully to the right the same button works.
